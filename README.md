EvalEgress (Ingenious AI) provides a real‑time boundary‑scanner that measures data egress during AI agent evaluations. It helps organizations identify and control unintended data leaks by scanning repository files, configuration texts, and other inputs without making network calls or accessing live systems. The service stores minimal metadata, redacts secret‑like values, and offers a free tier for quick assessments, with paid plans for deeper analysis and compliance reporting.
